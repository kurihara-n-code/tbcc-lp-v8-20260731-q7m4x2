# TBCC 4ヶ月即戦力プログラム LP

このフォルダは、現行版から分岐したデザイン強化版です。ヒーロー導線、実績バッジ、カード表現、CTA、フォームまわりの視覚的な訴求を高めています。

2026年6月14日のLPミーティング内容をもとに制作した、PC・スマートフォン対応のランディングページです。

参照LPの次の特徴を取り入れています。

- 黒を基調とした大きなファーストビュー
- 金色の強調帯
- 赤い資料請求CTA
- 幅約1000pxの縦長レイアウト
- 写真を大きく使った章立て
- コースタブ
- 比較表
- 卒業生詳細表示
- FAQアコーディオン
- スマートフォン下部の追従CTA

参照サイトの画像、文章、ロゴは使用していません。

## ファイル構成

- `index.html`: ページ構造
- `content.js`: コース、比較表、FAQなどの編集用データ
- `styles.css`: デザインとレスポンシブ表示
- `app.js`: タブ、詳細表示、フォームの動作
- `images/assets/`: 既存TBCCサイトから配置したWebP画像

## 会議内容から反映した項目

- 「4ヶ月で即戦力」を中心メッセージに設定
- 約6名の少人数制
- 実技中心の短期集中学習
- ホリスティック医学の考え方
- 現場インターンシップ
- 就職・独立開業支援
- 昼間・夜間の受講枠
- 習得レベル別の3コース
- 授業時間、学費、定員、キャリア支援の比較
- グループの治療院ネットワークと実績

## 未確定の内容

次の内容は議事録でも確認事項となっているため、断定せず「確認中」「仮」と表示しています。

- 正式なスクール名称とロゴ
- 正式なコース名
- 各コースの学費
- 授業時間と総時間数
- 開講曜日と昼間・夜間の時間割
- 就職実績の数値と根拠
- 卒業生インタビュー

確定後は主に`content.js`を書き換えます。

## 画像を変更する

`index.html`、`content.js`、`styles.css`内の`images/assets/...`を変更します。
同じファイル名で画像を上書きする場合、HTMLやCSSの修正は不要です。

本番写真は横幅1200px以上のWebPを推奨します。

## フォームについて

現在はデモフォームのため、入力内容は送信されません。
公開時にGoogleフォーム、formrun、HubSpot、WordPress、独自APIなどへ接続してください。

## 公開前チェック

- 商標確認後の正式名称・ロゴ
- コース名、期間、定員、学費
- 就職実績・店舗数・開業実績の最新値
- 比較表の根拠資料
- 卒業生・講師・学生写真の掲載許諾
- 医療行為と誤認させない表現
- 特定商取引法に基づく表記
- プライバシーポリシー
- フォーム送信先
